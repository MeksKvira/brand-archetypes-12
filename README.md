# 🎭 ბრენდის 12 არქეტიპი (Brand Archetypes Framework)

ეს რეპოზიტორი წარმოადგენს ბრენდის 12 არქეტიპის სტრატეგიულ გზამკვლევს დიზაინერებისა და ბრენდ-სტრატეგებისთვის.

## 📂 არქეტიპების ჩამონათვალი

1. **Innocent (უდანაშაულო)** — ოპტიმიზმი, სიმარტივე, პატიოსნება
2. **Everyman (რიგითი/მოქალაქე)** — მიკუთვნებულობა, რეალიზმი, სანდოობა
3. **Hero (გმირი)** — სიმამაცე, ძალა, მიზანმიმართულობა
4. **Outlaw / Rebel (ამბოხებული)** — თავისუფლება, რევოლუცია, წესების მსხვრევა
5. **Explorer (მკვლევარი)** — აღმოჩენები, დამოუკიდებლობა, თავგადასავალი
6. **Creator (შემოქმედი)** — ინოვაცია, წარმოსახვა, ავთენტურობა
7. **Ruler (მმართველი)** — კონტროლი, სტატუსი, ლიდერობა
8. **Magician (ჯადოქარი)** — ტრანსფორმაცია, ხედვა, სასწაული
9. **Lover (მოყვარული / ეშხიანი)** — ვნება, ინტიმურობა, ესთეტიკა
10. **Caregiver (მზრუნველი)** — მფარველობა, თანაგრძნობა, მხარდაჭერა
11. **Jester (მასხარა / ხუმარა)** — სიხარული, იუმორი, აწმყოთი ტკბობა
12. **Sage (ბრძენი)** — ჭეშმარიტება, ცოდნა, ანალიზი
